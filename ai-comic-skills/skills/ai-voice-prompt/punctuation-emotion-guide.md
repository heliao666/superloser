# 标点符号→情感语气映射速查手册

## 1. 标点符号→情感语气映射表

### 问号 (?)

- 语气: 疑问/不确定/反问
- 声音特征: 句末音调上扬, 语速稍慢
- 适用场景: 询问、质疑、反问、不确定
- 示例:
  - "你确定？" → 疑问,音调上扬
  - "真的吗？" → 惊讶+疑问
  - "你觉得呢？" → 征求意见

### 感叹号 (!)

- 语气: 强调/愤怒/警告/激动
- 声音特征: 音量增大, 咬字加重, 语速可能加快或放慢(取决于情绪)
- 适用场景: 命令、警告、激动、愤怒、惊喜
- 示例:
  - "站住！" → 命令,声音加大
  - "太好了！" → 惊喜,声音明亮
  - "我警告你！" → 警告,声音压低但加重

### 逗号 (,)

- 语气: 停顿/思考/犹豫
- 声音特征: 中间有短暂停顿, 语速稍慢
- 适用场景: 思考中说话、列举、犹豫
- 示例:
  - "我觉得，也许，我们可以试试" → 犹豫,多处停顿
  - "首先，我们需要找到线索" → 思考,逻辑停顿

### 省略号 (...)

- 语气: 犹豫/拖长/未尽之意
- 声音特征: 声音渐弱, 尾音拖长, 可能有停顿
- 适用场景: 犹豫不决、话未说完、回忆、悲伤
- 示例:
  - "我本来想说的...可是..." → 犹豫,声音渐弱
  - "那些日子..." → 回忆,声音放轻
  - "也许吧..." → 不确定,尾音拖长

### 破折号 (——)

- 语气: 突然转折/强调后半句
- 声音特征: 前半句停顿, 后半句语气突变
- 适用场景: 话锋一转、揭示真相、强调
- 示例:
  - "我以为他是好人——直到那天晚上" → 转折,语气突变
  - "答案只有一个——" → 悬念,停顿后强调

### 句号 (。)

- 语气: 陈述/肯定/结束
- 声音特征: 语调平稳, 尾音下沉收住
- 适用场景: 陈述事实、下结论、平静叙述
- 示例:
  - "事情就是这样。" → 肯定,尾音收住
  - "我决定了。" → 决断,语气坚定

## 3. 同一台词不同标点的效果对比

### 台词: "你是不是也想我呀"

- 无标点: 你是不是也想我呀 → 平铺直叙, 机器人感
- 问号: 你是不是也想我呀？ → 撒娇疑问, 语气上扬
- 感叹号: 你是不是也想我呀！ → 兴奋激动, 声音明亮
- 省略号: 你是不是也想我呀... → 羞涩犹豫, 声音渐弱

### 台词: "我没事"

- 句号: 我没事。 → 平静陈述, 尾音收住
- 感叹号: 我没事！ → 强装坚强, 声音加大
- 省略号: 我没事... → 明显有事, 声音发虚
- 逗号+省略号: 我没事，真的没事... → 自我安慰, 声音渐弱

### 台词: "你走吧"

- 句号: 你走吧。 → 平静放手
- 感叹号: 你走吧！ → 愤怒驱赶
- 省略号: 你走吧... → 不舍但无奈
- 破折号: 你走吧——别再回来了 → 决绝, 语气突变

### 台词: "为什么"

- 问号: 为什么？ → 真正的疑问
- 感叹号: 为什么！ → 愤怒质问
- 省略号: 为什么... → 绝望无力
- 逗号+问号: 为什么，为什么会这样？ → 崩溃追问
