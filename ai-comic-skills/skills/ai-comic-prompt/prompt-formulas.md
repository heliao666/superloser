## 1. Seedance 2.0 六步提示词公式

### 第一步：定基础参数

设定时长、比例、分辨率、画质。

```
时长:5s, 比例:16:9, 分辨率:1080p, 画质:电影级
```

常用参数值：

| 参数 | 可选值 |
|------|--------|
| 时长 | 3s, 5s, 10s |
| 比例 | 16:9, 9:16, 1:1, 4:3, 21:9 |
| 分辨率 | 720p, 1080p, 4K |
| 画质 | 标清, 高清, 电影级, 动画级 |

### 第二步：加画质+稳定词

防止生成过程中画质下降。

```
画质增强, 细节丰富, 稳定输出, 无闪烁
```

常用画质稳定词组合：

- 通用：`画质增强, 细节丰富, 稳定输出, 无闪烁`
- 写实风：`超写实, 肤质细腻, 光影真实, 稳定输出, 无闪烁`
- 动画风：`线条清晰, 色彩饱满, 帧率稳定, 无闪烁`
- 水墨风：`墨色层次分明, 留白自然, 渲染稳定, 无闪烁`

### 第三步：写主体+动作链

描述角色外观与连续动作。

```
一个[角色描述], [动作1], 然后[动作2]
```

示例：

```
一个穿白色汉服的少女, 缓缓转身, 抬手拂去肩上落花
```

动作链编写要点：

- 动作按时间顺序排列，用逗号或"然后"连接
- 每个动作只包含一个动词核心
- 动作之间需有逻辑连贯性
- 避免同时描述两个以上并行动作

更多示例：

```
一个戴眼镜的青年, 低头翻阅古籍, 猛然抬头望向窗外
一个身披铠甲的战士, 拔剑出鞘, 向前冲锋
一个扎双马尾的女孩, 歪头微笑, 伸手接住飘落的雪花
```

### 第四步：加场景+光线+氛围

描述环境、光照与情绪基调。

```
在[场景描述], [光线条件], [氛围词]
```

示例：

```
在月下竹林, 皎洁月光从竹叶间洒下, 清冷幽静
```

常用光线词：

| 光线类型 | 提示词 |
|----------|--------|
| 自然光 | 晨光, 正午阳光, 夕阳余晖, 皎洁月光, 星光 |
| 人工光 | 烛光, 灯笼光, 霓虹灯光, 舞台聚光灯 |
| 特效光 | 丁达尔光, 逆光剪影, 光斑, 光晕, 体积光 |

常用氛围词：

| 氛围 | 提示词 |
|------|--------|
| 温暖 | 温馨, 柔和, 治愈, 恬静 |
| 冷峻 | 清冷, 肃杀, 压抑, 阴森 |
| 热烈 | 热血, 激昂, 奔放, 喧嚣 |
| 神秘 | 诡异, 迷离, 幽深, 空灵 |

### 第五步：加镜头+运镜

指定镜头运动方式与景别。

```
[运镜方式], [景别]
```

示例：

```
缓慢推进, 中景转近景
```

常用运镜方式：

| 运镜 | 提示词 | 效果 |
|------|--------|------|
| 推 | 缓慢推进 / 快速推进 | 靠近主体，增强压迫感或亲密感 |
| 拉 | 缓慢拉远 / 快速拉远 | 远离主体，展现环境 |
| 摇 | 左摇 / 右摇 / 上摇 / 下摇 | 水平或垂直扫视 |
| 移 | 左移 / 右移 / 跟移 | 平行移动，跟随主体 |
| 升降 | 升镜头 / 降镜头 | 垂直运动，俯仰视角切换 |
| 环绕 | 环绕拍摄 / 360°环绕 | 围绕主体旋转 |
| 固定 | 固定镜头 / 静止镜头 | 不动，营造稳定感 |
| 手持 | 手持镜头 / 晃动镜头 | 模拟真实视角，增加临场感 |

常用景别：

| 景别 | 提示词 | 取景范围 |
|------|--------|----------|
| 大远景 | 大远景 | 人物极小，以环境为主 |
| 远景 | 远景 | 人物全身及周边环境 |
| 全景 | 全景 | 人物全身 |
| 中景 | 中景 | 人物膝盖以上 |
| 近景 | 近景 | 人物胸部以上 |
| 特写 | 特写 | 人物面部或局部细节 |
| 大特写 | 大特写 | 极小局部（眼、手、唇等） |

景别转换写法：

```
远景转中景
中景转特写
全景缓慢推进至近景
```

### 第六步：加负面提示词

排除不想要的生成结果。

```
--no 变形, 模糊, 闪烁, 多余肢体, 文字水印
```

### 完整六步组合示例

## 2. 六维度万能提示词公式

适用于任何AI视频工具的通用提示词框架：

```
[主体] + [核心动作] + [画面边界/背景] + [镜头调度] + [光影色彩] + [时间节奏]
```

### 维度详解

#### 维度一：主体

画面核心对象的完整描述。

```
[数量][年龄/身份][体型][服装][配饰][标志性特征]
```

示例：

```
一位二十岁的白发剑客, 身形修长, 穿墨色长袍, 腰悬玉佩, 左眼有竖瞳
```

#### 维度二：核心动作

主体正在执行的主要运动。

```
[动作动词][动作对象][动作方式/力度]
```

示例：

```
挥剑劈开瀑布水流
轻声念出咒语
猛力推开城门
```

#### 维度三：画面边界/背景

画面中主体之外的所有内容。

```
[前景元素], [中景环境], [远景/天空], [地面/水面]
```

示例：

```
前景:飘落的花瓣, 中景:石桥与小溪, 远景:青山薄雾, 地面:青石板路
```

#### 维度四：镜头调度

镜头位置、角度与运动。

```
[镜头角度], [镜头高度], [运镜方式], [景别]
```

示例：

```
低角度, 仰拍, 缓慢环绕, 中景
```

#### 维度五：光影色彩

光线方向、质感与整体色调。

```
[主光源方向及类型], [辅助光], [色调], [色彩饱和度]
```

示例：

```
左侧逆光, 暖色补光, 青橙色调, 高饱和
```

#### 维度六：时间节奏

画面内的时间流逝感与速度。

```
[速度感], [时间流逝方式], [节奏关键词]
```

示例：

```
慢动作, 时间正常流逝, 节奏舒缓
快速剪辑, 时间加速, 节奏紧凑
静止瞬间, 时间凝滞, 凝固感
```

### 完整六维度示例

**示例1——仙侠战斗：**

```
一位二十岁的白发剑客, 身形修长, 穿墨色长袍, 腰悬玉佩, 左眼有竖瞳 + 挥剑劈开瀑布水流 + 前景:飞溅水珠, 中景:百丈瀑布, 远景:云雾缭绕的山峰, 地面:碎石 + 低角度, 仰拍, 快速推进, 全景转中景 + 右侧逆光, 冷色环境光, 青蓝色调, 高饱和 + 慢动作, 时间凝滞, 凝固感
```

**示例2——都市日常：**

```
一个戴圆框眼镜的男大学生, 穿米色风衣, 背帆布包 + 低头看手机, 猛然抬头 + 前景:飘落的银杏叶, 中景:人行道与咖啡店, 远景:城市天际线, 地面:落叶铺满的砖路 + 平视, 固定镜头, 中景 + 顶部自然光, 暖色路灯, 金橙色调, 中饱和 + 正常速度, 时间自然流逝, 节奏舒缓
```

## 4. 小说转剧本提示词模板

将小说段落转换为可拍摄的剧本格式。

### 输出格式

```
场景: [INT/EXT] [地点] - [时间]
人物: [出场角色列表]
---
[镜头指示]
角色A: (发声方式) 台词
[叙事描述]
```

格式说明：

- INT = 室内, EXT = 室外
- 镜头指示用方括号标注，如 `[近景]` `[跟移]`
- 发声方式用圆括号标注，如 `(低声)` `(怒吼)` `(自语)`
- 叙事描述用于补充画面中非台词的信息

### 转换示例

**原文（小说段落）：**

> 苏晚宁推开书房的门，屋内烛火摇曳，映出满墙的古籍。她快步走到书架前，指尖划过一排排书脊，忽然停住，抽出一本泛黄的手札。翻开第一页，上面只写了四个字——"勿信此人"。她的手微微发抖，烛火也随之晃了一下。

**转换后（剧本格式）：**

```
场景: INT 古风书房 - 夜
人物: 苏晚宁
---
[中景] 苏晚宁推开书房门, 烛火摇曳, 满墙古籍映入眼帘。
[跟移] 苏晚宁快步走到书架前, 指尖划过一排排书脊。
[特写] 指尖停住, 抽出一本泛黄手札。
[大特写] 翻开第一页, 上面写着"勿信此人"四个字。
[近景] 苏晚宁: (低语) 勿信此人……
[特写] 她的手微微发抖, 烛火随之晃动。
```
